# Lattes2ORCID · Convertitore privato da XML Lattes a BibTeX

**Lingue:** [English](README.md) · [Português (Brasil)](README.pt-BR.md) · **Italiano**

**Trasferisci le pubblicazioni da Lattes a ORCID senza inviare l'intero curriculum a un server.**

[Lattes2ORCID](https://cecil-ia-labs.github.io/lattes2orcid/) è un'applicazione indipendente, gratuita e open source di **[Cecil-IA Labs](https://www.cecilialabs.com/)**. Converte le pubblicazioni presenti nell'XML esportato dalla Plataforma Lattes in un file BibTeX da controllare e importare successivamente in ORCID.

**[Apri il convertitore](https://cecil-ia-labs.github.io/lattes2orcid/)** · **[Codice sorgente](https://github.com/cecil-ia-labs/lattes2orcid)** · **[Il laboratorio](https://www.cecilialabs.com/)**

## Come funziona

1. Esporta il curriculum dalla Plataforma Lattes in formato **XML**.
2. Apri l'applicazione pubblica e seleziona il file.
3. Controlla il riepilogo e scarica il file **.bib**.
4. Verifica le citazioni prima di importarle in ORCID.

**Il tuo XML rimane nel browser.** La versione pubblica esegue la conversione localmente e non invia il file ai nostri server.

### Privacy dei ricercatori

L'XML esportato dalla piattaforma Lattes/CNPq può contenere numerosi dati personali. Prima di affidarlo a servizi di terzi, leggi l'informativa sulla privacy e verifica il trattamento previsto. **Non stiamo insinuando che il servizio citato utilizzi impropriamente questi dati.**

La nostra versione pubblica elabora l'XML interamente nel browser e non lo carica sui nostri server. L'utente mantiene il controllo del file originale e del risultato BibTeX.

## Ambito e limiti

La versione pubblica converte la **produzione bibliografica** del CV in BibTeX. L'importazione in ORCID resta manuale, mentre le altre sezioni del curriculum non sono ancora supportate. Controlla sempre i risultati e conserva una copia dell'XML.

La **v2 è ancora in sviluppo e non è stata rilasciata pubblicamente**.

Lattes2ORCID **non è un servizio ufficiale** di CNPq, Plataforma Lattes o ORCID. Il software viene fornito senza garanzie ai sensi della licenza MIT.
